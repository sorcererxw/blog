# Vendored fonts

Source: Google Fonts CSS API, fetched 2026-11-09 with the same Chrome user agent as Next 16.2.6. These unmodified Latin subsets preserve the configured Libre Bodoni 400/500/600 and Courier Prime 400/700 weights. Libre Bodoni is one variable WOFF2 file. Non-Latin characters use the existing system fallback. Builds use next/font/local and need no font API access.

Upstream family licenses are included beside the assets.
